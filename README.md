# 📊 CPI Inflation Analysis – Excel

## 📌 Project Overview

This project focuses on the analysis of **Consumer Price Index (CPI)** data using Microsoft Excel.

The objective of the project is to clean, structure, and analyse CPI data to identify inflation trends across different expenditure categories and compare CPI behaviour between **Rural and Urban sectors**.

The analysis also examines changes across time and compares **Pre-COVID and Post-COVID** periods.
